# Xaero's World Map — Full World Map Mod

[![Download Latest](https://img.shields.io/github/v/release/ChromeStorkAwaken/xaeros-world-map-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/ChromeStorkAwaken/xaeros-world-map-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A full-screen world map for Minecraft that maps every chunk you visit with biome colors and waypoints.

![Xaero's World Map — Full World Map Mod Preview](https://cdn.modrinth.com/data/NcUtCpym/354080f65407e49f486fcf9c4580e82c45ae63b8_96.webp)

## Features

- Full-screen world map rendered from visited chunks
- Biome color overlays and dimension switching
- Shared multiplayer map support with server integration
- Works with Xaero's Minimap waypoints seamlessly
- Low memory usage even on massive explored maps

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
